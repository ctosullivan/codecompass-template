## What it's for, based on how it's referenced

`legacy-reconciliation/TEMPLATE.md` describes its own step as happening
"once a fresh documentation draft has been written from a knowledge
snapshot and committed on its own" — and names *this* guide as the
place that first-draft-writing step belongs, explicitly calling out that
it should **not** be folded into the first draft itself:

> see `optional-clean-room-workflow/conceptual-documentation-guide.md`

So this guide's apparent role is: given a frozen `snapshots/` bundle for
a topic, how do you actually write the first, fresh documentation draft
from it — before any comparison against legacy docs happens, and
(implicitly, to keep that later comparison meaningful) without letting
the old narrative docs' framing leak into the new draft prematurely.

the overall workflow, not as the guide itself.
